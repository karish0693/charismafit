# CharismaFit

## Problem
People struggle to achieve fitness goals because plans are generic and not personalized.

## Users
- Students
- Professionals
- Fitness beginners

## MVP Features
- Signup/Login
- Fitness Profile
- Goal Setting
- Workout Plan Generation
- Workout Logging
- AI Coach Chat

## Success Criteria
A user can:
1. Create account
2. Set goal
3. Get workout plan
4. Log workouts
5. Receive AI coaching
